# Visual Assets

This folder contains the public visual asset set for `skill-security-auditor`, using a calm dark interface style with muted teal accents and abstract audit tooling imagery.

| File | Purpose |
| --- | --- |
| `banner.svg` | Wide README header or GitHub social preview artwork. |
| `card.svg` | Square repository card for directories, catalogs, and release posts. |
| `icon.svg` | Minimal shield/check mark for compact placement. |
| `preview.png` | Rendered overview of the asset family. |

## Usage

- Use `banner.svg` near the top of the repository README.
- Use `card.svg` when a square thumbnail works better than a wide banner.
- Use `icon.svg` for compact documentation, package listings, or favicon-style placement.
- Use `preview.png` in release notes or asset reviews when a single rendered image is useful.

The artwork is original abstract illustration. It does not include brand logos, status marks, personal references, or claims beyond the repository's documented purpose.
