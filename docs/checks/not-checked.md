# not-checked

Severity: medium. OWASP Agentic Skills Top 10: AST08.

A file could not be checked.

A file could not be checked: a binary, a document format, a language with no analyzer, a file over the size limit, a link, or a file the system refused to open. Unchecked files make the verdict at least REVIEW.

```text
assets/tool.bin
```

## Not flagged

